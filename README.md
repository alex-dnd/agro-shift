# Пятница. Релиз. Урожай

Веб-игра для IT-платформы РСХБ.Цифра. Ты дежурный инженер цифровой фермы: до вечерней отгрузки 2 часа, а события сыплются одно за другим. Нужно сохранить урожай, воду и работоспособность систем, распоряжаясь единственным инженером.

- **Играть:** https://alex-dnd.github.io/agro-shift/
- **Пример встраивания через iframe:** https://alex-dnd.github.io/agro-shift/embed.html

## Об игре

- Смена — 6 событий с 16:00 до 17:55, одна партия занимает 3–5 минут.
- Три показателя фермы: урожай, вода, системы. Итоговый балл — отгруженный урожай минус штраф, если вода или системы упали ниже 25.
- Один инженер: отправив его на задачу, ты теряешь его на несколько событий.
- Решения имеют отложенные последствия: долговременные эффекты и цепочки событий, которые возвращаются позже в той же смене.
- Финальное событие — «Обновление сортировщика» в 17:55: релиз в пятницу вечером.
- Живая схема фермы: поле, теплица, коровник, отгрузка, бак с водой и сервер реагируют на события, а неудачные решения оставляют следы до конца смены.
- Персонажи: сосед Михалыч, водитель, бригадир Оля и ФермаБот.
- Итоговый отчёт с журналом смены, 8 достижений, лучший результат сохраняется в браузере.

## Встраивание на сайт

Игра — статическая сборка без сервера и внешних запросов. Минимальный код:

```html
<iframe
  src="https://alex-dnd.github.io/agro-shift/"
  title="Игра «Пятница. Релиз. Урожай»"
  width="100%" height="900"
  style="border:0; max-width:820px"
  loading="lazy"
></iframe>
```

Чтобы фрейм подстраивался под высоту игры, можно добавить обработчик: игра сама отправляет родительской странице сообщение `agro-shift:height` через `postMessage`.

```html
<script>
  window.addEventListener('message', function (e) {
    if (e.data && e.data.type === 'agro-shift:height') {
      document.querySelector('iframe[title*="Урожай"]').style.height = e.data.height + 'px'
    }
  })
</script>
```

Если браузер запрещает хранилище внутри iframe, игра продолжает работать, просто не сохраняет рекорд и достижения.

## Стек

React 19, TypeScript, Vite. Графика — встроенный SVG и CSS-анимации, без внешних картинок и библиотек.

## Запуск локально

Нужен Node.js 22.

```bash
npm install
npm run dev      # режим разработки
npm run build    # сборка в папку dist
npm run preview  # просмотр собранной версии
```

## Структура

| Файл | Что внутри |
|---|---|
| `src/game.ts` | Правила игры: состояние, применение решений, эффекты, подсчёт балла, достижения |
| `src/events.ts` | События смены, варианты решений, цепочки последствий, реплики персонажей |
| `src/App.tsx` | Экраны: меню, правила, смена, итоговый отчёт |
| `src/FarmMap.tsx` | Живая схема фермы на SVG |
| `src/Characters.tsx` | Персонажи и облачка с репликами |
| `public/embed.html` | Демо-страница со встраиванием через iframe |

Логика игры отделена от интерфейса: `game.ts` и `events.ts` не зависят от React.
